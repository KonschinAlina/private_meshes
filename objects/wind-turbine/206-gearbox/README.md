# Gearbox

Gearbox with torque arms and oil cooler, between the main shaft and the generator.

Part of the wind turbine model by sorinar329 (IEA-3.4-130-RWT dimensions), exported from `sorinar329/cognitive_robot_abstract_machine` branch `windturbine_maintenance`. Generated by `scripts/export_turbine_parts.py`; do not edit by hand.

`model.urdf` loads independently using only local `assets/*.glb` files; each fault state has its own `model_<state>.urdf`.
Licensed under BSD-3-Clause, pending confirmation by the model's author (see LICENSE.txt and NOTICE.md); keep both with every copy.

Coordinates are metres, Z up. Size 3.100 × 2.600 × 2.510 m (X × Y × Z). Origin at the turbine link's origin, axes parallel to the turbine's `gearbox` link frame.
Use a unique URDF parser prefix for each instance. Masses and inertias are placeholders (1 kg, unit inertia), as in the turbine model; collisions are its boxes and cylinders.
